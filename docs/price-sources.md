На всех четырёх найдена модель Ryzen 5 7600 OEM с артикулом 100-000001015, а не 7600X и не BOX. Это контроль одного товара, не подтверждение покрытия всех 24 товаров или стабильного обновления по расписанию.

Прямой запрос к Регарду дал 18 280 рублей в JSON-LD. XCOM-SHOP вернул 17 813 рублей в микроразметке. Значения в поисковом индексе отличались, поэтому поисковые сниппеты нельзя импортировать как текущие цены. Наблюдения фиксируют результат проверки и не гарантируют цену при покупке. Данные не импортированы в каталог.

Регион по умолчанию зависит от магазина. Для честного сравнения нужно закрепить один город и условия покупки.

## Проверенные, но не выбранные

- DNS: прямой запрос вернул HTTP 401. Пока менее пригоден для автоматического обновления.
- ОНЛАЙН ТРЕЙД: ответ HTTP 200 оказался короткой технической страницей без подтверждённого каталога и цены. Код 200 сам по себе не доказывает успешное получение данных.

## До включения синхронизации

1. Сопоставить точные артикулы всех товаров, цвет, комплектность, объём, BOX/OEM.
2. Закрепить город; различать обычную, клубную и акционную цену.
3. Проверить разрешённый способ регулярного получения данных, лимиты и условия источника. Не обходить ограничения доступа.
4. Сохранять магазин, прямую ссылку, дату, наличие и условия цены. При ошибке оставлять прежнюю цену и дату.
5. Повторить обновление и подготовить отдельное хранилище предложений: один products.price не хранит четыре независимых предложения.

На сайте добавлены ссылки на выбранные магазины. Мониторинг цен пока не включён; демонстрационные значения сохраняют свою пометку. Проверки не выдаются за работающую синхронизацию.
